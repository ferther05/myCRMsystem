# CRM 视觉契约与主题映射

在确定整体视觉、主题或跨页面组件样式时使用。本文件给出约定方法，具体色值、尺寸与源码路径以用户选择及实际前端为准。

## 统一主题

- 新建主题前定位已有 tokens、Element Plus 配置与全局样式，扩展同一来源。不要只在项目根目录查找 `tokens.css` 后直接套用默认值。
- 无既定风格时，可提出浅色中性背景、清晰品牌色、少量语义状态色的桌面后台方案，并标注为候选。配色建议不等于用户已确认品牌。
- 使用带 `crm` 前缀的语义变量，例如 `--crm-color-brand`、`--crm-bg-page`、`--crm-bg-panel`、`--crm-text-main`、`--crm-text-secondary`、`--crm-border`、`--crm-color-success/warning/danger`。间距、字号、圆角采用同一组分级，避免每页独立定义。
- 4px 基准间距、14px 正文与表格、小圆角是可选起点；根据屏幕、中文文本和操作密度调整。表格不能为了展示型留白占用过多纵向空间。
- 同步主题代码与说明。说明记录每项用途、组件映射、对比度验证和已确认选择，不复制整本外部配色手册。

## Element Plus 映射

按项目实际版本核对支持的 CSS/Sass 变量。常见映射包括：

- `--el-color-primary` → CRM 品牌色。
- `--el-color-success/warning/danger` → CRM 语义状态色。
- `--el-text-color-primary/regular` → 主要/常规文字层级。
- `--el-bg-color`、`--el-bg-color-page` → 面板/页面背景。
- `--el-border-color`、`--el-border-radius-base` → 边框与基础圆角。

选择 CSS 覆盖或 Sass 主题时，核对主色的浅色/深色派生变量及 hover、active、disabled 状态；只覆盖 `--el-color-primary` 不保证所有派生色自动一致。保留项目既有命名时使用映射，不强制重命名所有样式。

复用 `ElTable`、`ElForm`、`ElDialog`、`ElDrawer`、`ElMessage` 等实际已有组件，设计补充展示与布局约定。避免重写组件的校验、焦点管理或弹窗机制。图标使用项目已选的图标体系，不混用 emoji、字体图标与多个新图标包。

## 数据展示与交互

- 客户名、联系人等长文本定义换行或省略规则，完整信息仍有可访问的查看入口。表格操作列位置一致，主要动作可识别，危险动作说明对象与后果。
- 金额按后端约定的币种、精度与舍入显示，右对齐并考虑等宽数字。日期注明实际业务时区，避免浏览器转换后跨日。
- 状态颜色配合标签文字；错误与冲突给出恢复动作。加载、禁用与无权限具有不同含义，不共用模糊的灰色状态。
- 对无数据、筛选无结果、权限不足和接口失败分别提供合适反馈；不在错误状态展示合成统计来掩盖失败。
- 图表颜色与业务含义稳定对应。回款率、转化率等显示单位和时间范围；必要时保留数据列表或文本摘要，避免仅靠图形传达结果。

## 可访问性与适配

- 验证实际前景/背景组合，包含 hover、选中、图表标签和深色变体（如本次需要）。参考色表不作为验证证据。
- 普通文字 4.5:1，大文字 3:1；大文字按 WCAG 的字号/字重定义判断。适用的非文字控件与图形辨识要求为 3:1，不把禁用组件例外误当正文例外。
- 表单有可关联标签、必填说明和可定位的错误；键盘能打开、关闭并返回弹窗。保持可见焦点，不以 `outline: none` 消除唯一焦点提示。
- 窄屏可采用筛选折叠、明细抽屉和必要的表格横向滚动，但导航与关键动作始终可达。小屏不是复制一张固定宽度桌面截图。
- 外部字体、深色模式及复杂动效按用户需求和实际部署条件选用。优先复用中文友好的既有字体，不把 Google Fonts 网络访问设为运行前提。
