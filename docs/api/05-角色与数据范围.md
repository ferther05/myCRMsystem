# PERM 角色与数据范围

对应任务清单 C9；[返回总文档](00-全项目接口说明与请求示例.md)。权限包含后端动作授权、SQL 数据范围和响应字段白名单；菜单与路由用于辅助交互。

## 已实现的权限

- ADMIN：全部账号/团队/内部账号申请；建号、角色团队调整、启停、密码重置及账号申请审核。私人客户查询为全系统。
- MANAGER：本团队成员、本人当前团队的账号申请；可代新专员申请、重新提交自己被驳回的申请。私人客户查询为本团队。
- SPECIALIST：本人账号资料，不能访问账号审批或管理动作。私人客户查询为本人归属。
- 公海客户基础查询向登录角色开放，电话在 SQL 中脱敏；短号统一返回 `****`，空值仍为 null。信用代码、决策链、合同金额、附件路径等不在当前 VO 中返回。
- 原负责人：当前 ownership_seq 对应的有效交接日志，且 handover_readonly_until 尚未到期，才额外获得客户基础查询；标记 readonly=true。过期或旧归属轮次不能继续访问。
- 商机协作不授予客户全档案访问；本轮客户查询没有以协作关系绕过范围。商机专属协作入口将在商机模块接入。
- 未授权详情统一 40400，既不泄露对象是否存在，也不能通过猜 ID 访问。分页 SQL 和总数均包含相同范围。

账号、团队、申请入口和动作权限见 [USER](03-内部账号申请与管理.md)。权限变化通过账号版本撤销旧令牌；后续登录和受保护请求均实时读取数据库身份。

## PERM-01 客户范围分页 GET /api/customers

参数 `page=1`、`size=20`、`sea=PRIVATE|PUBLIC`（默认 PRIVATE）。身份、owner/team 条件由后端生成，客户端传 ownerId/teamId 不会扩大权限。

成功 data 示例：

```json
{"total":1,"list":[{"id":321,"customerName":"示例客户","primaryPhone":"138****5678","sourceCode":null,"industryCode":null,"customerStatus":"NEW","seaType":"PUBLIC","ownerId":null,"ownerName":null,"teamName":null,"readonly":true}]}
```

PRIVATE 范围内的电话完整显示；PUBLIC 无论管理员或其他角色都脱敏。数据来自真实数据库，空库返回 total=0、list=[]。

## PERM-02 客户基础详情 GET /api/customers/{id}

正整数 id，成功 data 为 PERM-01 单条对象。同样应用 owner/team、公海、交接有效期与字段白名单；不能绕过列表权限。该接口只返回基础档案摘要，不包含联系人全档案、跟进或商业资料。

错误：无登录 40100，失效身份 40102，需先改密 40301，范围外/不存在 40400，参数错误 40000/40001，依赖故障 50300。

## 页面和请求示例

`/customers` 查询 PRIVATE、`/public-pool` 查询 PUBLIC；支持分页、刷新、查看基础详情、加载/空/错误状态。页面明确说明本轮只开放查询，新增、编辑、跟进、领取等动作未开放。

```powershell
Invoke-RestMethod 'http://127.0.0.1:8080/api/customers?sea=PRIVATE&page=1&size=20' -Headers $headers
Invoke-RestMethod 'http://127.0.0.1:8080/api/customers?sea=PUBLIC&page=1&size=20' -Headers $headers
Invoke-RestMethod 'http://127.0.0.1:8080/api/customers/321' -Headers $headers
```

实现：`module/auth/security/DataScope.java`、`module/system/mapper/AccountMapper.java`、`module/customer/`；动作授权用 Spring Security `@PreAuthorize`，关系过滤用参数化 MyBatis SQL。沿用 18 表简化方案，不增加角色权限关联表、全 SQL 拦截器或自建 ThreadLocal。
