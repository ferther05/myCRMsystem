# 第一个大模块 用户与权限管理

对应任务清单前三项：用户注册与登录、用户个人信息维护、角色差异化数据访问与操作权限。适用于当前本地运行版本。页面入口 http://127.0.0.1:5173/login；账号初始资料见你本地保存的 Word，修改密码后以新密码为准。

## 分别用了什么技术

- **Spring Boot 3 + Java 17**：提供后端接口，把账号、申请和资料操作组织成服务。
- **Spring Security 6 + JWT**：验证登录身份，拦截越权操作。浏览器请求携带令牌；停用、改权限、重置密码后旧令牌失效。
- **BCrypt**：数据库只保存密码哈希，不能直接查回原密码。管理员忘记密码时通过重置解决。
- **MyBatis-Plus + MyBatis + MySQL 8**：查询/保存账号和申请；SQL 限制本人、团队、全量范围；唯一键防重名，事务和版本防重复审批、覆盖与审计缺失。
- **Vue 3 + Element Plus**：登录、个人中心、账号表格和申请审核表单。**Vue Router** 管理页面和角色入口；**Pinia** 保存当前身份；**axios** 给请求加令牌并处理错误。
- **Redis 7**：当前连接可用；本模块会话和权限以数据库为准，没有把 Redis 当作账号或审批的存储。

记忆方式：前端负责收集输入和展示结果；后端确认身份与规则；MySQL 保存最终结果。隐藏按钮不能代替后端权限。

## 功能一 账号申请 开通 登录

**经理操作**

1. 登录经理账号 → 审批中心 → 提交账号申请。
2. 填写新成员账号、姓名、可选电话/邮箱和原因 → 提交。
3. 结果：创建本团队的待审核专员，不能登录；经理不能为他人申请管理员权限或选择其他团队。
4. 查看审核状态/意见 → 被驳回时点“重新提交” → 再次进入待审核，历史处理动作仍保留。

**管理员操作**

1. 审批中心 → 审核申请 → 选择通过或驳回，填写意见；通过时设置初始密码。
2. 通过效果：账号启用，使用初始密码登录后强制改密。驳回效果：账号继续不能登录，经理可重新提交。
3. 账号管理 → 创建账号 → 填账号、姓名、角色、团队及初始密码 → 直接开通，跳过申请。管理员不绑定团队，经理和专员必须绑定启用团队。
4. 账号管理 → 查询/刷新，按账号或姓名搜索、按状态筛选，支持分页。
5. 对他人点“角色与状态” → 修改角色/团队/启停 → 保存后该账号旧会话失效，重新登录才获得新权限；停用后不能登录，启用后可登录。
6. 有客户、负责商机、合同或有效协作关系时，角色/团队调整被拒绝，先处理业务交接；停用本身不自动释放客户。
7. 对他人点“重置密码” → 设置不同的新初始密码 → 原密码和旧令牌失效，使用新密码登录后再次强制改密；重置不会自动启用停用账号。

管理员不能在管理表格修改本人角色/启停或重置本人密码，避免误锁账号；本人改密从个人中心操作。当前使用已有华东、华南团队，不提供团队新增/删除。

**所有角色操作**

- 登录：账号和密码正确且账号、团队可用 → 进入工作台；首次登录或被重置密码 → 先改密。
- 改密：输入当前密码、新密码、确认密码 → 保存 → 返回登录；旧密码及旧令牌失效。
- 退出：右上角账号菜单 → 确认退出 → 后端撤销当前令牌，前端清理身份。
- 同一账号在另一处重新登录 → 旧会话失效；刷新页面会向后端重新确认身份。

## 功能二 个人信息维护

个人中心 → 编辑资料 → 修改姓名、电话、邮箱 → 保存。姓名必填，电话/邮箱可清空；保存后持久化到数据库，当前页面与顶栏姓名同步更新，刷新仍保留。

“取消”放弃未保存输入；“刷新信息”重新读取后端。登录账号不能修改；角色和团队只能由管理员管理。保存资料自动更换当前令牌；其他标签页发现身份令牌变化后需重新确认登录。

密码规则：8～64 位，至少一个英文字母和一个数字，可用英文符号，不能有空格或中文。账号规则：3～64 位，以字母/数字开头，可包含点、横线、下划线；账号和非空邮箱不能重复。

## 功能三 角色与数据访问

- **专员**：维护本人资料；账号接口只返回本人；客户范围查询只看本人负责客户。
- **经理**：看本团队成员和客户；为本团队新专员申请账号，查看/重提自己的申请；不能直接建号、改权限或审核开通。
- **管理员**：看全系统账号和客户；管理账号、角色团队、启停与密码重置；审核所有内部账号申请。
- **公海**：所有登录角色只查基础信息，电话在后端脱敏；信用代码、决策链、金额、附件等不返回。
- **交接只读**：当前归属轮次的交接记录有效期内，原负责人可查基础摘要；过期后失去额外访问权。实际交接操作以后在客户模块实现。

可执行查询：客户管理/客户公海 → 查询列表 → 翻页/刷新 → 查看详情。没有数据时显示空列表；当前没有录入客户的按钮。浏览器中更改 userId、teamId 或对象 id，仍不能扩大后端权限；越权详情按不存在处理。

## 常见反馈代表什么

- “请先修改初始密码”：先完成强制改密。
- “登录已失效”：重新登录，常见于改密、重置、角色团队调整或另一处重新登录。
- “没有权限”：当前角色不能执行该动作，换有权限的账号。
- “数据已变化或冲突”：可能账号/邮箱重复、记录刚被登录或修改、审批已处理；刷新核对后重试。
- “先完成业务交接”：账号仍关联业务，当前不能调整角色/团队。
- “基础服务暂不可用”：检查后端、MySQL、Redis 及本地配置，表单保留后重试。
