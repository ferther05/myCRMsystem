论文题目 | 基于SpringBoot的中小企业客户关系管理（CRM）系统 |  | 一、选题主要内容
选题背景与问题聚焦：中小企业销售管理普遍依赖Excel与微信，客户资料分散、商机跟进无痕、业绩统计滞后，超60%企业缺乏专业CRM工具，导致客户流失与漏跟严重，本课题据此提出面向中小企业的CRM系统开发。
核心业务方向：围绕客户档案管理、联系人管理、商机阶段流转（线索-跟进-报价-成交-赢单）、合同登记、回款计划与记录、逾期提醒、任务提醒及操作日志等销售全流程，构建数字化闭环。
管理机制设计：重点研究多角色权限模型（销售专员、经理、管理员）与商机状态机设计，实现公海客户分配与回收、销售漏斗统计及基于ECharts的可视化看板（业绩排行、转化率、回款趋势）。
技术路线概要：基于Spring Boot+Vue前后端分离架构，采用Spring Security+JWT进行认证授权，MyBatis-Plus处理持久化，MySQL存储业务数据，Redis缓存，前端使用Element Plus和ECharts。
二、选题意义与应用价值
理论意义：探索B/S架构下RBAC权限模型与有限状态机在销售流程管理中的工程实践，积累前后端分离技术栈在轻量级企业系统中的应用经验。
实践价值：为中小企业提供低成本、易部署、可落地的销售管理工具，切实解决客户资源浪费、跟进不及时、决策缺乏数据支撑等问题，提升客户转化率和销售规范性。
三、实现方案
技术选型：Java 17、Spring Boot 3.0、MyBatis-Plus、Spring Security+JWT；前端Vue 3+Element Plus；数据库MySQL 8.0，缓存Redis 7.0，可视化ECharts。
系统架构：B/S前后端分离，后端提供RESTful API，前端负责界面交互，权限控制基于RBAC，接口鉴权通过JWT令牌，全局状态用Pinia管理。
权限设计：预设系统管理员、销售经理、销售专员三种角色，使用Spring Security注解实现接口级权限校验，在行级数据隔离基础上增加字段级可见性与敏感字段脱敏。
核心模块实现策略：客户管理支持增删改查、标签分类、跟进记录与公海自动回收（按商机阶段与活跃度双维度判定）；商机管理定义"线索→跟进→报价→成交→赢单"状态机，并计算漏斗数据；合同回款实现分期计划与逾期自动检测；看板通过ECharts绘制多种图表。
开发流程：需求调研→数据库设计→后端分层开发→前端页面构建→集成测试→部署优化，按模块迭代完成。
四、研究目标
功能目标：完成客户管理、商机管理、合同回款、数据看板及权限管理五大模块，实现销售全流程数字化闭环。
技术目标：掌握Spring Boot、Vue、JWT认证、ECharts等关键技术，熟悉前后端联调与系统部署流程。
