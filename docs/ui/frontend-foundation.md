# 前端框架与页面约定

2026-10-18，用户选择 A：浅灰页面、白色卡片、深蓝侧栏、蓝色主按钮。依据详细设计第 11 章、过程指南阶段 1/2 和已确认账号规则；采用 Vue 3 / Element Plus，保持毕业设计所需的简单模块结构。

## 页面结构

登录页在桌面使用左侧品牌说明、右侧登录表单；窄屏保留品牌和表单。改密为独立安全页面，首次改密不显示业务导航，普通改密可返回来源页。

工作空间使用侧栏、顶栏、主内容和页脚。侧栏按销售业务、协同管理、经营分析与系统管理分组；菜单和路由共用 `router/modules.js` 的角色定义，避免两套配置不一致。宽度不超过 760px 时使用可打开/关闭的导航抽屉；桌面支持收起侧栏。

已实现页面为登录、首次/普通改密、工作台、只读个人中心、403、404。客户、公海、商机、合同回款、审批、团队、任务日志、数据看板和系统设置保留可识别的待开发页面。工作台只显示真实账号、所属团队、密码状态与后端健康结果，不生成演示销售额、客户数或待办。

## 主题与组件

主题源为 `frontend/src/assets/styles/theme.css`，公共样式为 `global.css`。主色 `#245ee5`，侧栏 `#142641`，页面 `#f3f5f9`，卡片 `#ffffff`，正文 `#172b49`，次要文字 `#596b83`。成功/警告/错误使用 `#167753`、`#956316`、`#bd3242`，同时保留文字提示。

Element Plus 主色、派生色、文本、边框和背景均在同一主题映射。主要正文基准 14px，面板圆角 10px；使用系统中文字体和 Element Plus 图标，无外部字体依赖。主要按钮 hover 使用更深蓝色 `#1d4bb7`，输入框边界 `#7c8ba1`，占位文字 `#66758b`。

公共组件包括 PageHeading、DataTable、StatusTag 和 BaseChart。DataTable 支持加载、空列表、错误重试及分页；BaseChart 准备柱状/折线/饼图/漏斗类型，监听尺寸并在销毁时释放实例。后续模块按真实 API 传入数据；本轮仅完成公共组件编译检查，业务表格和图表仍需在使用它们的模块验证。

## 交互与适配

表单有关联标签、自动填充提示、隐藏密码输入、提交中防重和对应错误。密码不自动 trim，不进入本地存储。错误后保留可纠正信息，登录密码错误时清空密码；页面离开清空密码字段。

身份确认、健康检查和提交操作分别展示加载态；连接失败有重试；401、首次改密和403使用对应跳转；404提供返回入口。登录与改密规则、接口映射见 [认证模块](../api/02-账号认证与密码.md)。

键盘有焦点提示和跳至主内容入口，抽屉复用 Element Plus 焦点管理；尊重 `prefers-reduced-motion`。桌面 1440×1000、窄屏 390×844 已实际检查，登录/工作台/改密均无页面水平溢出。

本轮计算的相邻颜色对比度：正文对白 14.21:1、次要文字对白 5.45:1、次要文字对页面背景 4.99:1、主按钮白字 5.52:1、hover 白字 7.66:1、侧栏文字 9.43:1、占位文字对白 4.69:1；输入边界对白 3.46:1。以上覆盖这些实际配色组合，不等于全站无障碍认证。禁用态和装饰性面板浅边框按各自用途处理。

浏览器结果与截图位置见 [前端验证记录](../frontend-verification.md)。后续业务页面沿用此结构和主题，新增可执行操作需要先有真实后端接口和权限规则。

## 用户与权限页面增量

2026-10-18：沿用现有 A 风格与公共 PageHeading/DataTable。`/system` 是管理员账号管理（筛选表格＋创建/权限启停/重置弹窗），`/team` 复用成员表格，经理只查询本团队并跳转申请；`/approvals` 是账号申请与审核表格，经理提交/重提，管理员填写审核意见与初始密码。`/account` 增加可保存/取消的资料表单；保存后更新当前身份。`/customers` 和 `/public-pool` 是基础只读查询入口，明确提示后续业务动作尚未开放。

新表单有字段校验、提交中禁用、失败保留/重试与版本冲突提示；申请和账号状态同时显示文字。窄屏表格在容器内横向滚动，弹窗限制在屏幕内；真实浏览器结果见 `docs/user-permissions-verification.md`。这些页面不是完整客户或全业务审批模块。
