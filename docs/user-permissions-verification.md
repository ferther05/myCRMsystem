# 用户与权限管理验证记录

验证日期：2026-10-18。对应任务清单前三项 C7「用户注册与登录」、C8「用户个人信息维护」、C9「角色差异化数据访问与操作权限」。使用说明见 [模块技术与操作指南](module-guides/01-用户与权限管理.md)。

## 本次实现与环境

在现有 Spring Boot 3 / Java 17 / Spring Security 6 / JWT / MyBatis-Plus 后端和 Vue 3 / Element Plus 前端上补齐内部账号申请、审核、直接建号、角色团队与启停、密码重置、本人资料维护，以及当前用户、团队和客户基础查询的数据范围。

采用用户确认的方案：经理代本团队新专员申请，管理员审核并设置初始密码；管理员也可直接创建账号。不开放公众注册。复用现有 18 张表，无表结构迁移。

真实依赖为本机 MySQL 8 与 WSL Redis 7；后端监听 `127.0.0.1:8080`，前端监听 `127.0.0.1:5173`。测试账号使用独立随机凭据，不依赖或修改原有演示账号的密码。样例数据、测试断言与运行检查均不能代表正式业务数据。

- 23 项真实环境集成测试：账号管理 8 项、认证流程 11 项、Redis 故障降级 1 项、基础设施 3 项。

新增 `AccountManagementIT` 的 8 项测试覆盖：

1. 三种角色的用户列表、详情、团队范围、分页总数、匿名访问与参数校验；篡改对象 ID 不能扩大权限。
2. 本人资料字段白名单、联系方式校验、持久化、旧令牌撤销及新令牌可用。
3. 经理申请 → 管理员驳回 → 原经理重提 → 管理员通过；待审核账号不可登录、开通后强制改密、账号名防重及跨团队隔离。
4. 管理员直接建号、重置密码、停用/启用、团队调整及旧令牌失效。
5. 同一申请并发审核仅一项成功，另一项返回冲突；只生成一次成功审核审计。
6. 模拟审计写入异常时，账号创建和关联更新回滚，不留下半成品。
7. 实际客户记录的本人/团队/全量范围、公海电话脱敏、详情越权、交接到期与旧归属轮次失效。
8. 经理降权后旧令牌失效，新身份不能继续使用经理操作。

可重复测试源：[AccountManagementIT.java](../backend/src/test/java/com/bishe/crm/AccountManagementIT.java)。本次 XML 结果位于 `backend/target/surefire-reports/`、`backend/target/failsafe-reports/`；它们是本机生成产物，后续测试会更新。
